# Chase Xie

盯盘、背单词、改简历，来回切太烦，就做成网页了。都放在 [chaestblog.pages.dev](https://chaestblog.pages.dev/)，想用直接点。

## 现在开着的

**[加密终端](https://crypto-funding-arbitrage.pages.dev/)**  
资金费率、链上 Meme、清算热图、期权墙。我自己看盘用的那一页。  
源码：[crypto-funding-arbitrage](https://github.com/shangchaovo/crypto-funding-arbitrage)

**[外资研报](https://fresearch.cc.cd/)**  
UBS、Citi、摩跟、大摩对这些股票怎么看，目标价多少；发完之后行情跟没跟上也会记一笔。  
源码：[ib-research](https://github.com/shangchaovo/ib-research)

**[WordPaper](https://wordpaper.pages.dev/)**  
今天要背的词做成壁纸。雅思、四六级、考研、日语都有。  
源码：[wordpaper](https://github.com/shangchaovo/wordpaper)

**[简历工坊](https://resume-5lv.pages.dev/)**  
校招简历：左边填，右边一张 A4，导出 PDF。  
源码：[resume-site](https://github.com/shangchaovo/resume-site)

主页上还有几个没单独开源的：[Predict Pulse](https://predict-pulse.signal-harbor.workers.dev/?view=sentiment)、[Signal Harbor](https://signal-harbor-terminal.signal-harbor.workers.dev/#overview)、[交易每日报告](https://dailytrade.cc.cd/)。

最早做的资金费率表和期权分析页，后来并进加密终端了，仓库还留着：[funding-dashboard](https://github.com/shangchaovo/funding-dashboard)、[crypto-options-analyzer](https://github.com/shangchaovo/crypto-options-analyzer)。
