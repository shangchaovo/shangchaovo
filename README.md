# 市场研究与日常工具

我做市场研究工具，也写一些自己会用的小应用。一个是为了不用在五家交易所之间来回切，另一个只是为了每天打开电脑时能多看两眼单词。

[个人站 · 作品与近况](https://chaestblog.pages.dev/) · [个人站源码](https://github.com/shangchaovo/chaestblog)

## 如果你也看市场

| 我想知道…… | 从这里开始 |
| --- | --- |
| 投行调高某只美股的目标价后，它真的跑赢了 SPY 吗？ | [FResearch](https://fresearch.cc.cd/) 把机构的公开评级、目标价和发布后的相对表现放在一起。[源码](https://github.com/shangchaovo/ib-research) |
| 同一个币，在哪家交易所的资金费率更高？ | [加密终端](https://crypto-funding-arbitrage.pages.dev/) 可以横向比较费率，再切到估算的清算热区或 BTC / ETH 期权墙。[源码](https://github.com/shangchaovo/crypto-funding-arbitrage) |
| 怎样让 AI 助手和我看同一张图，而不是来回贴截图？ | [ChartBridge · 图桥](https://github.com/shangchaovo/chartbridge#readme) 在本地共用图表、交易计划和回测；从仓库的快速开始入手。 |

## 不看盘的时候

- **背单词** → [WordPaper](https://wordpaper.pages.dev/)：把今天的新词和复习词排成壁纸。网页能导出 PNG，Mac 伴侣可设系统桌面。[源码](https://github.com/shangchaovo/wordpaper)
- **准备校招** → [简历工坊](https://resume-5lv.pages.dev/)：左边改经历，右边看一页 A4 放不放得下，最后从浏览器导出 PDF。[源码](https://github.com/shangchaovo/resume-site)
- **和朋友一起坐火车** → [同车余票](https://rail-same-train-pages.pages.dev/)：先查余票、比较路线；购票仍去官方渠道。[源码](https://github.com/shangchaovo/rail-ticket-assistant)

**找老项目？** [旧资金费率看板](https://github.com/shangchaovo/funding-dashboard)和[独立期权分析器](https://github.com/shangchaovo/crypto-options-analyzer)仍保留代码，对应的网页功能已并入加密终端。还有一个小工具：[在 Mac 上导入东方财富自选](https://github.com/shangchaovo/eastmoney-mac-import)。
